# app-shell Specification

## Purpose
TimeLog の全画面に共通する外枠（アプリ名、共通レイアウト、表示言語）と、最初に表示されるトップページの振る舞いを定める。

## Requirements

### Requirement: トップページの表示
システムは、ルートパス `/` にアクセスしたユーザーに TimeLog のトップページを表示しなければならない（SHALL）。トップページには `create-next-app` の初期表示を残してはならない。

#### Scenario: トップページにアクセスする
- **WHEN** ユーザーが `/` を開く
- **THEN** アプリ名「TimeLog」と、アプリが時間を記録するためのものだと分かる日本語の説明が表示される
- **AND** Next.js の初期テンプレートのロゴや案内文は表示されない

### Requirement: 共通レイアウト
システムは、すべてのページを共通のヘッダー付きレイアウトで表示しなければならない（SHALL）。ヘッダーにはアプリ名「TimeLog」を表示し、トップページへのリンクにする。

#### Scenario: ヘッダーからトップページへ戻る
- **WHEN** ユーザーが任意のページでヘッダーのアプリ名「TimeLog」を選ぶ
- **THEN** トップページ `/` に移動する

### Requirement: 日本語での表示
システムは、ページを日本語の文書として配信しなければならない（SHALL）。ページのタイトルにはアプリ名「TimeLog」を含める。

#### Scenario: ページの言語とタイトル
- **WHEN** ユーザーがいずれかのページを開く
- **THEN** HTML の `lang` 属性は `ja` である
- **AND** ブラウザのタブに表示されるタイトルに「TimeLog」が含まれる

### Requirement: 画面幅への対応
システムは、スマートフォン幅（幅 375px 程度）からデスクトップ幅まで、横スクロールなしでトップページと共通レイアウトを表示しなければならない（SHALL）。

#### Scenario: スマートフォン幅で表示する
- **WHEN** ユーザーが幅 375px の画面でトップページを開く
- **THEN** ヘッダーと本文が画面内に収まり、横スクロールが発生しない
