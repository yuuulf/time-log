# Proposal

## Why

「今日の記録」はタイムライン（カレンダー）で時間の使い方を見られるようになったが、「過去の記録」は新しい順の一覧だけで、1 週間の時間の配分や付け忘れた空き時間が分かりにくい。「過去の記録」でも、カレンダーの週表示のように 1 週間を曜日の列のタイムラインで見られるようにし、今日の記録と同じ操作で過去の記録を足したり直したりできるようにする。

## What Changes

- 「過去の記録」の見出しの横に、今日の記録と同じ「一覧」「カレンダー」のボタングループを置く。最後に選んだ表示はブラウザに覚えておく（今日の記録とは別に覚える。最初は一覧）
- カレンダーでは 1 週間（月曜日〜日曜日）を表示する。左に 0 時〜24 時の目盛り、右に月〜日の 7 つの列を並べ、各列の上に日付（「11/16（月）」）とその日の合計時間を出す。記録は今日のタイムラインと同じ帯（プロジェクトの色、タスク名と時刻を 1 行、重なり・短い記録は横に並べる、記録中は決まった高さ）で置く。見出しは週の期間（「2026年11月16日〜2026年11月22日」）にする
- 週は「前の週」「次の週」で 1 週ずつ切り替える。今週より先には進めない。表示中の週は URL（`?week=2026-11-16`）に含め、再読み込みしても同じ週を出す。カレンダーのときは月の切り替えと期間の入力欄の代わりに週の切り替えを出す
- 一覧からカレンダーに切り替えると、表示していた月・期間の最後の日を含む週（今週より先なら今週）を出す。カレンダーから一覧に切り替えると、表示していた週の月曜日を含む月を出す
- 今日のタイムラインと同じく、日の列の空いている場所を押すとその日の記録の入力欄が開いて追加でき、帯を押すと修正・削除できる。今より後（今日の今の時刻より後と、明日以降の列）は追加できず、追加用のポインタも出さない
- 開いたときは、今週なら今の時刻のあたり、ほかの週はその週でいちばん早い記録のあたり（記録がなければ 8 時）までスクロールする
- 「CSV 出力」はカレンダーのときも置き、表示中の週の記録を出す
- 今日のタイムラインの部品を、1 日でも 7 日でも使える形に分ける（今日の記録の見た目と操作は変えない）

### スコープ外（やらないこと）

- 月のマス目のカレンダー（月表示）、複数の週を縦に並べる表示
- 週の始まりを日曜日にする設定
- 帯のドラッグでの移動・長さの変更
- 「集計」ページのカレンダー表示
- 期間の指定（開始日〜終了日）をカレンダーで表示すること（カレンダーは週単位）

### README.md の更新

README の「使い方」の「過去の記録」の説明に、カレンダー（週）への切り替えと、週の切り替え、カレンダーからの追加・修正・削除を追記する。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `time-tracking`: 「過去の記録」の表示の切り替え、週のカレンダーの表示と週の切り替え、週のカレンダーからの記録の追加・修正・削除の要件を加える。今日のタイムラインの要件（帯の並べ方・入力欄・初期の時刻）は週のカレンダーでも同じに使う

## Impact

- `lib/time-entries/history.ts`: `week` のクエリを解釈し、週の表示（`mode: "week"`）を返す。切り替え先の URL を求める
- `lib/time-entries/today-view.ts`: 「過去の記録」用の Cookie を足す（表示の型は共通）
- `components/time-entries/`: タイムラインの格子・日の列・入力欄の開閉を、1 日（今日）と 7 日（週）で使える部品に分ける。週のカレンダー・週の切り替え・表示の切り替えの部品を足す
- `components/time-entries/EntryHistory.tsx`・`HistoryContent.tsx`: Cookie と URL から表示を決め、一覧かカレンダーを出す
- `lib/messages.ts`: 週の切り替え・見出しの文言
- `README.md`: 「使い方」に追記
- 依存パッケージ・DB の変更なし
