# Proposal

## Why

記録は「過去の記録」で 1 件ずつ見られるが、ある月や期間に合計で何時間働いたか、どのプロジェクトにどれだけ時間を使ったか、何日働いたかは、自分で足し算しないと分からない。記録を振り返りや報告に使えるよう、期間を決めて集計を表示する画面を作る。

## What Changes

- 新しい「集計」ページ（`/summary`）を追加し、サイドバーのリンクに「集計」を「過去の記録」と「プロジェクト」の間に置く
- 期間の決め方は「過去の記録」と同じにする
  - 開いたときは今月。「前の月」「次の月」で 1 か月ずつ切り替える
  - 開始日と終了日を入力して期間を指定できる。「月ごとの表示」で今月に戻る
  - 月・期間は URL に含め、再読み込みしても同じ期間を集計する
- 期間について次の 4 つを表示する
  - 期間の合計時間
  - 稼働日数（記録が 1 件でも開始された日の数）
  - 週ごとの合計時間（月曜始まりの週。期間からはみ出す部分は含めない）
  - プロジェクトごとの合計時間（「プロジェクトなし」を含め、時間の長い順）
- 「過去の記録」の期間の切り替え（月の切り替え・期間の入力欄）を共通の部品にして、「集計」でも使う。「過去の記録」の見た目と動きは変えない

### スコープ外（やらないこと）

- グラフ（棒グラフ・円グラフなど）での表示
- 日ごと・タスク名ごとの集計
- 集計結果の CSV などへの書き出し
- 記録中の記録の経過時間を合計に含めること（作業時間を表示しない今の扱いに合わせる）
- 1 日の目標時間や残業時間の計算

### README.md の更新

README の使い方に「集計」ページの説明を足す必要がある。同じ PR で更新する。

## Capabilities

### New Capabilities

- `time-summary`: 指定した月や期間に記録した作業時間を、合計・週ごと・プロジェクトごとの時間と稼働日数にまとめて表示し、働いた量を振り返れるようにする

### Modified Capabilities

- `app-shell`: 「サイドバー」のページのリンクに「集計」を加え、「画面幅への対応」に「集計」ページを加える

## Impact

- `app/summary/page.tsx`（新規）とその部品（`components/summary/`）
- `lib/summary/`（新規）: 記録から集計を計算する処理
- `lib/time-entries/history.ts`・`components/time-entries/HistoryContent.tsx`: 期間の決め方と切り替えの部品を「集計」と共通にする
- `lib/time.ts`: 週の始まりや日付の表示の関数を追加
- `components/layout/SidebarNav.tsx`・`lib/messages.ts`
- DB のテーブルの変更・依存パッケージの追加はなし
