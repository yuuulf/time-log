# Proposal

## Why

集計した月や期間の作業時間を、報告や請求の資料として人に渡したり手元に残したりしたいが、今は画面で見るしかない。集計を PDF にして保存できるようにする。

## What Changes

- 「集計」ページの期間の見出し（「2026年11月」「2026年10月1日〜2026年10月15日」）の横に、「PDF 出力」のアイコンボタンを置く
- ボタンを選ぶとブラウザの印刷ダイアログを開く。ユーザーは送り先に「PDF に保存」を選んで PDF にする
- 印刷（PDF）には、期間の見出しから下の情報（期間の見出し、合計時間・稼働日数と数え方の注記、週ごとの集計、プロジェクトごとの集計）だけを出す。サイドバー（幅の狭い画面の上部のメニュー）、ページの見出し「集計」、月の切り替え・期間の入力欄、「PDF 出力」ボタンは出さない
- 画面がダークモードでも、印刷は白い背景・黒い文字のライトの配色で出す
- 印刷ダイアログで保存するときの既定のファイル名を、集計した月・期間が分かるもの（例: 「集計 2026年11月」）にする。印刷が終わったらタブのタイトルはアプリ名に戻す
- 期間の入力に誤りがあって集計を表示していないときは、「PDF 出力」ボタンを表示しない

### スコープ外（やらないこと）

- サーバーで PDF ファイルを作ってダウンロードさせること（PDF 生成ライブラリや日本語フォントの追加はしない）
- 印刷ダイアログを経ずに PDF を直接保存すること
- 「過去の記録」など、集計以外のページの PDF 出力
- 集計の画面にない情報（記録 1 件ずつの明細、グラフなど）を PDF に足すこと
- 用紙サイズ・向き・余白の指定（ブラウザの印刷ダイアログの設定に任せる）

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `time-summary`: 集計を印刷ダイアログ経由で PDF に出力する要件を追加する

## Impact

- `components/summary/`: 「PDF 出力」ボタン（Client Component）を追加し、`SummaryContent.tsx` の期間の見出しの横に置く。印刷に出さない部分に印刷用のクラスを付ける
- `app/summary/page.tsx`: ページの見出し「集計」を印刷に出さない
- `components/layout/SidebarShell.tsx`: サイドバーと上部のメニューを印刷に出さない（ほかのページの印刷でもサイドバーは出なくなる）
- `app/globals.css`: 印刷のときはライトの配色のトークンを使う
- `lib/messages.ts`: ボタンの名前と、保存の既定のファイル名の文言を追加する
- 依存パッケージの追加なし
- README.md: 使い方の「集計」の説明に「PDF 出力」ボタンを追記する（更新が必要）
