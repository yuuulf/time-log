# Proposal

## Why

「プロジェクト」ページの一覧は、説明まで表示し、編集もその場でフォームを開く形のため、プロジェクトが増えると一覧が長く見にくい。一覧は見分けるのに必要な項目だけにし、プロジェクトごとの詳細画面で全項目を確認・変更できるようにする。

## What Changes

- 一覧の各行には、色のアイコン・プロジェクト名・クライアント名だけを表示する（説明は表示しない）
- プロジェクト名をリンクにし、選ぶとプロジェクトの詳細画面（`/projects/[id]`）に移動する
- 一覧の編集ボタンをなくし、縦三点リーダーの「その他の操作」ボタンを置く。メニューにはごみ箱のアイコンと「削除」があり、今と同じく確認してから削除する（記録が紐づいていれば削除できない旨を表示する）
- 詳細画面では、名前・色・クライアント名・説明をすべて表示し、記録の一覧と同じくその場で編集できる。文字の項目は値を変えてフォーカスが外れたら保存し（説明以外は Enter でも確定）、Escape で元に戻す。色は選んだら保存する。入力に誤りがあるときは保存せず、値を残して理由を表示する
- 詳細画面には一覧へ戻るリンクを置く。見つからないプロジェクトの詳細画面では、見つからない旨と一覧へ戻るリンクを表示する
- 詳細画面を開いているときも、サイドバーの「プロジェクト」を選ばれている表示にする

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `projects`: 「プロジェクトの一覧」の表示項目とメニュー、「プロジェクトの編集」を詳細画面でのその場の編集に、「プロジェクトの削除」をメニューからの削除に変え、「プロジェクトの詳細」の要件を追加する
- `app-shell`: 「サイドバー」で詳細画面でも「プロジェクト」を選ばれている表示にし、「画面幅への対応」の対象に詳細画面を加える

## スコープ外

- 詳細画面での削除（削除は一覧のメニューだけで行う）
- 詳細画面に、そのプロジェクトの記録や作業時間の合計を表示すること
- プロジェクトの登録欄の変更（一覧の上の登録欄は今のまま）
- ブラウザのタブのタイトルにプロジェクト名を出すこと（今と同じ「プロジェクト」のまま）

## README.md の更新

必要。使い方の「プロジェクト」の説明を、一覧（色・名前・クライアント名）、名前から詳細画面へ移動してその場で編集、その他の操作のメニューからの削除に書き換える。

## Impact

- 新規: `app/projects/[id]/page.tsx`、`components/projects/ProjectDetail.tsx`（詳細と編集）・`ProjectDetailView.tsx`（DB を読むサーバー側）
- 変更: `components/projects/ProjectItem.tsx`（一覧の行）、`ProjectForm.tsx`（編集の役割をなくし登録専用に）、`ProjectsView.tsx`、`components/layout/SidebarNav.tsx`、`lib/messages.ts`、README.md
- サーバー側の処理（`updateProjectAction`・`deleteProjectAction`・入力チェック）とデータは変えない
- 新しい依存パッケージ: なし
