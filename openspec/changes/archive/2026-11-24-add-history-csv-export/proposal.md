# Proposal

## Why

記録を表計算ソフトで集計し直したり、勤怠や請求の資料に貼ったりするには、今は画面から 1 件ずつ写すしかない。「過去の記録」ページで表示している月・期間の記録を CSV ファイルとして保存できるようにし、TimeLog の外でも記録を使えるようにする。

## What Changes

- 「過去の記録」ページの期間の見出し（「2026年11月」「2026年10月1日〜2026年10月15日」）の横に「CSV 出力」のアイコンボタンを置く。選ぶと、表示中の月・期間に開始した記録を 1 件 1 行にした CSV ファイルがダウンロードされる
- 列は「日付」「開始時刻」「終了時刻」「作業時間（分）」「タスク名」「プロジェクト」。記録は古い順に並べる。記録中の記録は終了時刻と作業時間を空にして含める
- ファイルは Excel でそのまま開いても文字化けしない形（BOM 付きの UTF-8）にする。ファイル名は「記録 2026年11月.csv」のように期間の見出しを付ける
- 期間の入力に誤りがあるときはボタンを出さない。記録がない期間では、見出しの行だけの CSV になる

### スコープ外（やらないこと）

- 「集計」ページの集計結果の CSV 出力
- 期間を選ばずにすべての記録を出すこと（バックアップは既存の `npm run local:backup` で行う）
- CSV の読み込み（取り込み）
- 列や文字コードを選べるようにすること
- トップページの「今日の記録」からの出力（今日の分は「過去の記録」の今月か期間の指定で出せる）

### README.md の更新

README の「使い方」の「過去の記録」の説明に、CSV 出力ができることと CSV の列を追記する。

## Impact

- `app/history/export/route.ts`（新規）: `GET` の Route Handler。「過去の記録」ページと同じクエリ（`month` または `from`・`to`）を受け取り、CSV を返す
- `lib/time-entries/csv.ts`（新規）: 記録から CSV の文字列を作る
- `components/time-entries/HistoryContent.tsx`・`EntryList.tsx`: 期間の見出しの横に「CSV 出力」ボタンを置く
- `lib/messages.ts`: ボタンの名前・ファイル名・列名の文言を追加
- `README.md`: 「使い方」に追記
- 依存パッケージ・DB の変更なし
