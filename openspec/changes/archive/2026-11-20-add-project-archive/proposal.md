# Proposal

## Why

終わった案件のプロジェクトは、記録が紐づいているので削除できず、一覧や記録のプロジェクトの選択肢に残り続ける。プロジェクトをアーカイブして普段の一覧と選択肢から外し、必要なときだけアーカイブ済みの一覧で見られるようにする。

## What Changes

- 一覧の各行の「その他の操作」のメニューに、アーカイブのアイコンと「アーカイブ」を足す（「削除」の上）。選ぶとそのプロジェクトをアーカイブし、一覧から外す（確認は出さない。元に戻せるため）
- 一覧の「新規作成」の横に、アーカイブのアイコンボタン（「アーカイブ済み」）を置く。選ぶと「アーカイブ済みのプロジェクト」画面（`/projects/archived`）に移る
- アーカイブ済みの画面には、一覧へ戻るリンクと、アーカイブしたプロジェクトの一覧（色のアイコン・名前・クライアント名）を並べる。各行の「その他の操作」のメニューには「アーカイブ解除」と「削除」を置く。解除すると通常の一覧に戻る
- アーカイブしたプロジェクトは、記録の開始と記録の一覧のプロジェクトのプルダウンの選択肢に出さない。すでに紐づいている記録は、今までどおりそのプロジェクトのアイコンと名前を表示する
- アーカイブしたプロジェクトの詳細画面は今までどおり開いて編集でき、見出しの下にアーカイブ済みである旨を表示する
- DB の `projects` に、アーカイブした日時（`archived_at`、未アーカイブは null）を足すマイグレーション

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `projects`: 「プロジェクトの一覧」でアーカイブしたプロジェクトを除き、アーカイブ済みへのボタンとメニューの「アーカイブ」を加える。「プロジェクトのアーカイブ」「アーカイブ済みのプロジェクトの一覧」「アーカイブの解除」の要件を追加する
- `time-tracking`: 「アーカイブしたプロジェクトの扱い」の要件を追加する（選択肢から外し、紐づいた記録の表示は変えない）
- `app-shell`: 「画面幅への対応」の対象にアーカイブ済みの画面を加え、「サイドバー」で「プロジェクト」の下の画面すべてで「プロジェクト」を選ばれている表示にする

## スコープ外

- アーカイブしたプロジェクトでの記録の開始・再開を禁じること（選択肢から外すだけ。再開すると元の記録と同じプロジェクトで始まる）
- 一覧からまとめてアーカイブすること、アーカイブの日時の表示
- 「過去の記録」などでのプロジェクトによる絞り込み

## README.md の更新

必要。使い方の「プロジェクト」の説明に、その他の操作のメニューからのアーカイブ、アーカイブ済みの画面と解除、アーカイブしたプロジェクトが選択肢に出ないことを追記する。

## Impact

- DB: `projects.archived_at` を足すマイグレーション（`drizzle/0002_...sql`）。既存のプロジェクトは null（アーカイブしていない）
- 変更: `lib/db/schema.ts`、`lib/projects/repository.ts`（一覧をアーカイブの有無で分ける、アーカイブ・解除）、`lib/projects/actions.ts`、`components/projects/`（一覧の行のメニュー、一覧の上のボタン、詳細画面の表示）、`components/time-entries/`（選択肢の読み込み）、`components/projects/ProjectPicker.tsx`（今の値が選択肢にないとき）、`lib/messages.ts`、README.md
- 新規: `app/projects/archived/page.tsx` と、その中身の部品
- 新しい依存パッケージ: なし
