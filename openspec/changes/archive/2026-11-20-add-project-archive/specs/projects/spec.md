# Spec Delta

## ADDED Requirements

### Requirement: プロジェクトのアーカイブ
システムは、一覧の各行の「その他の操作」のメニューに、アーカイブのアイコンと文字の「アーカイブ」を「削除」の上に置き、選んだプロジェクトをアーカイブできるようにしなければならない（SHALL）。アーカイブは確認せずに行い、アーカイブしたプロジェクトは「プロジェクト」ページの一覧から外れる。アーカイブしたプロジェクトの詳細画面は今までどおり開いて編集でき、見出しの下にアーカイブ済みである旨を表示する。名前の重複のチェックは、アーカイブしたプロジェクトも含めて行う。

#### Scenario: プロジェクトをアーカイブする
- **WHEN** 一覧の「社内ツール」の「その他の操作」のメニューで「アーカイブ」を選ぶ
- **THEN** 「社内ツール」は「プロジェクト」ページの一覧から消え、アーカイブ済みの画面の一覧に表示される

#### Scenario: アーカイブしたプロジェクトの詳細を開く
- **WHEN** アーカイブした「社内ツール」の詳細画面を開く
- **THEN** 全項目が表示されて編集でき、アーカイブ済みである旨が表示される

#### Scenario: アーカイブしたプロジェクトと同じ名前で作成する
- **WHEN** 「社内ツール」をアーカイブした状態で、名前に「社内ツール」を入力して作成する
- **THEN** プロジェクトは作成されず、同じ名前のプロジェクトがある旨が表示される

### Requirement: アーカイブ済みのプロジェクトの一覧
システムは、「プロジェクト」ページの「新規作成」の横にアーカイブのアイコンの「アーカイブ済み」ボタンを置き、選ぶと「アーカイブ済みのプロジェクト」画面（`/projects/archived`）に移動しなければならない（SHALL）。この画面には「プロジェクト」ページの一覧へ戻るリンクと、アーカイブしたプロジェクトを登録した順に、色のアイコン・名前（詳細画面へのリンク）・クライアント名で並べる。各行の「その他の操作」のメニューには「アーカイブ解除」と「削除」を置く。アーカイブしたプロジェクトがないときは、その旨を表示する。

#### Scenario: アーカイブ済みの画面を開く
- **WHEN** 「社内ツール」をアーカイブした状態で、「プロジェクト」ページの「アーカイブ済み」ボタンを選ぶ
- **THEN** アーカイブ済みの画面に移動し、「社内ツール」が色のアイコン・名前・クライアント名付きで表示され、一覧へ戻るリンクがある

#### Scenario: アーカイブしたプロジェクトがない
- **WHEN** アーカイブしたプロジェクトがない状態でアーカイブ済みの画面を開く
- **THEN** アーカイブしたプロジェクトがないことを伝える文言が表示される

#### Scenario: アーカイブ済みの画面から削除する
- **WHEN** 記録が紐づいていないアーカイブ済みのプロジェクトの「その他の操作」のメニューで「削除」を選び、確認で削除を選ぶ
- **THEN** そのプロジェクトは削除され、アーカイブ済みの一覧から消える

### Requirement: アーカイブの解除
システムは、アーカイブ済みの画面の各行の「その他の操作」のメニューの「アーカイブ解除」で、プロジェクトのアーカイブを解除できるようにしなければならない（SHALL）。解除は確認せずに行い、解除したプロジェクトは「プロジェクト」ページの一覧に登録した順の位置で戻り、記録のプロジェクトの選択肢にも再び出る。

#### Scenario: アーカイブを解除する
- **WHEN** アーカイブ済みの画面で「社内ツール」の「その他の操作」のメニューの「アーカイブ解除」を選ぶ
- **THEN** 「社内ツール」はアーカイブ済みの一覧から消え、「プロジェクト」ページの一覧と、記録の開始のプロジェクトの選択肢に表示される

## MODIFIED Requirements

### Requirement: プロジェクトの一覧
システムは、「プロジェクト」ページ（`/projects`）で、アーカイブしていないプロジェクトを登録した順に一覧表示しなければならない（SHALL）。各プロジェクトには色のアイコン・名前・クライアント名だけを表示し、説明は表示しない。クライアント名が空のときは何も表示しない。名前はリンクにし、選ぶとそのプロジェクトの詳細画面に移動する。各行には縦三点リーダーのアイコンの「その他の操作」ボタン（メニューは「アーカイブ」「削除」）を置き、編集ボタンは置かない。一覧の見出しの横には、プラスのアイコンと文字の「新規作成」ボタンと、アーカイブ済みの画面へ移る「アーカイブ済み」ボタンを置く。プロジェクトが 1 件もないときは、まだプロジェクトがないことと「新規作成」から作成できることを伝える文言を表示する。

#### Scenario: プロジェクトを一覧で見る
- **WHEN** 「社内ツール」「A 社サイト改修」の順に登録した状態で「プロジェクト」ページを開く
- **THEN** 「社内ツール」「A 社サイト改修」の順に、それぞれの色のアイコン・名前・クライアント名が表示される
- **AND** 説明と編集ボタンは表示されず、各行に「その他の操作」ボタンがある

#### Scenario: プロジェクトがない
- **WHEN** プロジェクトが 1 件もない状態で「プロジェクト」ページを開く
- **THEN** まだプロジェクトがないことと、「新規作成」から作成できることを伝える文言が表示される

#### Scenario: プロジェクト名から詳細画面へ移動する
- **WHEN** 一覧の「社内ツール」の名前を選ぶ
- **THEN** 「社内ツール」の詳細画面に移動する

#### Scenario: 新規作成ボタンから登録画面へ移動する
- **WHEN** 「プロジェクト」ページで「新規作成」ボタンを選ぶ
- **THEN** プロジェクトの登録画面に移動し、登録欄は「プロジェクト」ページには表示されない
