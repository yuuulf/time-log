# Design

## Context

- ファビコンは `create-next-app` が置いた `app/favicon.ico` を Next.js のファイル規約でそのまま出している。`public/` ディレクトリはまだない
- 画面のライト・ダークは `app/globals.css` の `@media (prefers-color-scheme: dark)` でトークンを切り替えている。Tailwind の `dark:` も設定を変えておらず、同じメディアクエリで効く
- アプリ名は `components/layout/Sidebar.tsx`（サイドバー）と `components/layout/SidebarShell.tsx`（幅 768px 未満の画面上部）の 2 か所に、トップページへのリンクとして文字だけで出している
- 元の画像はユーザーが用意した `~/Downloads/icon_light.png`・`icon_dark.png`（どちらも 2000×2000px の PNG、約 180KB）。ライト用は白地に濃い灰色の時計、ダーク用は濃い灰色の正方形の地に白い時計で、どちらもチェックは青緑

## Goals / Non-Goals

**Goals:**

- ファビコンとアプリ名のロゴを、OS・ブラウザのライト・ダークに合わせて出し分ける
- ロゴの表示を 1 つの部品にまとめ、サイドバーと画面上部で使い回す

**Non-Goals:**

- 画像を SVG に描き直すこと
- 画像の変換を自動化するスクリプトや依存パッケージの追加

## Decisions

### 画像は背景を透過して縮小し、`public/` に置く

元の画像の背景を透明にしてから 512×512px に縮小し、`public/icon-light.png`・`public/icon-dark.png` として置く。ファビコンとサイドバーのロゴで同じファイルを使う。

- 透明にする範囲: 画像の四隅から、背景の色（ライト用は白、ダーク用は濃い灰色）に近い色でつながっている画素だけを透明にする。時計の針のように絵の内側に囲まれた部分は、背景と同じ色でも残す
- 境目の画素は、背景の色との近さに応じて半分透明にし、色から背景の色を差し引く。ふちのギザギザや背景の色のにじみを抑えるため
- 処理には Next.js が依存として入れている `sharp` を、その場限りの Node.js のスクリプトから使う。スクリプトはコミットせず、出来上がった PNG だけをコミットする
- 別案: macOS の `sips`。縮小はできるが透過ができないため使わない

- 2000px のままだとファビコンとして重く、表示する大きさ（最大でも数十 px）に対して大きすぎる。512px あれば高精細な画面でも足りる
- 別案: `app/icon.png` のファイル規約。1 枚しか置けず、`media` でライト・ダークを出し分けられないため使わない
- 別案: `sharp` を直接の依存に足してビルド時に変換する。一度変換すれば済むため足さない

### ファビコンはメタデータの `icons` で出し分ける

`app/layout.tsx` の `metadata.icons.icon` に、ライト用（`media` なし）とダーク用（`media: "(prefers-color-scheme: dark)"`）の 2 つを並べる。`app/favicon.ico` は削除する（残すとファイル規約で初期のファビコンも出てしまう）。

- ライト用に `media` を付けないのは、`media` に対応していないブラウザでもライト用が出るようにするため（Next.js のドキュメントの例と同じ並び）

### ロゴは `components/layout/AppLogo.tsx` にまとめる

`next/image` の `<Image>` を 2 つ並べ、ライト用に `dark:hidden`、ダーク用に `hidden dark:block` を付けて CSS で出し分ける。Next.js のドキュメント（`<Image>` の Theme detection）が勧める方法に沿う。

- 大きさは 24px 四方（文字 `text-lg` の高さに合わせる）。アプリ名とは `flex items-center gap-2` で並べる
- `alt=""` にして飾りとして扱い、リンクの名前を「TimeLog」のままにする
- 別案: `<picture>` と `getImageProps` で 1 つの要素にまとめる。読み込む画像が 1 枚で済むが、画像は小さく、2 か所のリンクで同じ部品を使うだけなので、ドキュメントの基本の方法を選ぶ
- 別案: JavaScript で今のテーマを調べて切り替える。サーバーで描くときにテーマが分からず、表示がちらつくため使わない

### 色・文言

- 画像の中の色は画像ファイルに含まれるもので、`@theme` のトークンの対象外とする
- 新しい画面の文言はない（ロゴは `alt=""` で、アプリ名は既存の `messages.app.name`）

## Risks / Trade-offs

- [チェックのまわりのふち（ライト用は白、ダーク用は灰色）は外側の背景とつながっているので透明になり、すき間として見える] → チェックと時計を分ける役目は変わらず、絵の印象はほぼ同じ。ブラウザでの確認で見え方を確かめる
- [境目に背景の色がわずかに残ることがある] → ライト・ダークの両方の背景の上で拡大して確かめ、目立つときはしきい値を調整して作り直す
- [Safari など一部のブラウザはファビコンの `media` を無視し、ダークモードでもライト用が出ることがある] → ライト用を `media` なしの既定にしてあるので、少なくともロゴは出る。ブラウザでの確認のタスクで実際の見え方を記録する
- [ブラウザはファビコンを強くキャッシュするため、変更後もしばらく古いアイコンが出ることがある] → 確認時はキャッシュを消すか新しいプライベートウィンドウで見る
