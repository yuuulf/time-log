# Proposal

## Why

記録の一覧では「プロジェクト → タスク名」の順に並ぶのに、トップページの記録中の枠とサイドバーの記録中のタスクでは、プロジェクトがタスク名の右側にあり、並び順がそろっていない。どこでも同じ順で読めるようにする。

## What Changes

- トップページの記録中の枠: プロジェクト（色のアイコンと名前）を 1 行目に、その下の行にタスク名を表示する。プロジェクトが紐づいていなければ、プロジェクトの行は出さない
- サイドバーの記録中のタスク: プロジェクトの色のアイコンをタスク名の左側に置く。名前は今と同じく文字で出さず、ポインタを合わせると表示する
- 読み上げの順も、プロジェクト名 → タスク名にそろう
- 開始時刻の位置を変える: 記録中の枠では見出し「記録中のタスク」の右に、サイドバーでは見出しのすぐ下に置く

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `time-tracking`: 「記録のプロジェクトの表示」で、記録中の枠とサイドバーのプロジェクトの位置をタスク名の前（記録中の枠は上の行、サイドバーは左側）に変える。「記録の開始」のシナリオの表示位置の記述を合わせる

## スコープ外

- サイドバーでプロジェクト名を文字で表示すること（アイコンだけのまま）
- 記録中の枠の停止ボタン・開始時刻の表示、記録の一覧の並び
- プロジェクトのない記録中の枠に「プロジェクトなし」と表示すること

## README.md の更新

必要。使い方の、プロジェクトのアイコンの位置（記録中の枠ではタスク名の右側、サイドバーではタスク名の右側）の記述を、記録中の枠ではタスク名の上の行、サイドバーではタスク名の左側に直す。

## Impact

- 変更: `components/time-entries/StartStopForm.tsx`（記録中の枠）、`components/layout/RunningTaskView.tsx`（サイドバー）と、それぞれのテスト、README.md
- サーバー側・データは変えない
- 新しい依存パッケージ: なし
