# Proposal

## Why

タブを切り替えて別の作業をしていると、TimeLog で記録中かどうかはタブに戻らないと分からず、止め忘れや付け忘れが起きやすい。記録中だけファビコンを別の絵にして、ブラウザのタブを見るだけで記録中だと分かるようにする。

## What Changes

- TimeLog のロゴ（通常のファビコンとサイドバー・画面上部のアプリ名の横のロゴ）を、ユーザーが用意した新しい絵（ストップウォッチとチェック。`l_デフォルト.png`・`d_デフォルト.png`）に変える
- 記録中のタスクがあるあいだ、ファビコンをユーザーが用意した記録中用の絵（ストップウォッチの中に停止の四角。`l_記録中.png`・`d_記録中.png`）に変える。記録中のタスクがなければ、TimeLog のロゴを出す
- 4 枚とも背景を透明にし、今のロゴと同じくブラウザ・OS のライト・ダークに合わせて出し分ける
- 記録の開始・終了・再開・修正・削除をしたとき、そのタブでは再読み込みしなくてもファビコンが切り替わる（サイドバーの記録中のタスクの表示と同じタイミング）
- どのページを開いていても、記録中ならファビコンは記録中用の絵になる

### スコープ外（やらないこと）

- 別のタブで記録を開始・終了したときに、ほかの開いているタブのファビコンをすぐ切り替えること（そのタブを再読み込みしたり、ページを移動したりしたときに切り替わる）
- タブのタイトル（「TimeLog」）を記録中に変えること
- 絵のデザインや作成（ユーザーが用意した画像を透過・縮小して使う）
- サイドバー・画面上部のアプリ名のロゴを記録中に変えること（ロゴは記録中でも新しい通常の絵のまま）
- ホーム画面に追加したときのアイコンや Web アプリのマニフェスト

### README.md の更新

README には画面の見た目やファビコンについての記述がないため、更新は不要と見込む。実装の最後に改めて確認する。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `app-shell`: 「ファビコン」の要件のロゴの絵をストップウォッチとチェックに改め、記録中のタスクがないときに限る。記録中のタスクがあるあいだは記録中用の絵を示し、記録の操作の後に再読み込みなしで切り替わる「記録中のファビコン」の要件を加える

## Impact

- `public/icon-light.png`・`public/icon-dark.png`: 新しい通常の絵に置き換える（ファビコンとアプリ名のロゴの両方に効く）
- `public/`: 記録中用のファビコンの画像（ライト用・ダーク用）を追加
- `components/layout/`: 記録中かどうかに合わせてファビコンを切り替えるクライアント部品を追加し、`RunningTaskView.tsx` から使う
- `app/layout.tsx` のメタデータのファビコン指定は今のまま（記録中でないときの絵として使う）
- 依存パッケージの追加はなし
