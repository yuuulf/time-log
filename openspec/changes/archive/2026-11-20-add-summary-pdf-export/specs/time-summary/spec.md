# Spec Delta

## ADDED Requirements

### Requirement: 集計の PDF 出力
システムは、「集計」ページの期間の見出しの横に「PDF 出力」のアイコンボタンを表示し、ユーザーがそれを選んだらブラウザの印刷ダイアログを開かなければならない（SHALL）。印刷には、期間の見出しから下の情報（期間の見出し、合計時間・稼働日数と数え方の注記、週ごとの集計、プロジェクトごとの集計）だけを出し、サイドバー、上部のメニュー、ページの見出し「集計」、月の切り替え・期間の入力欄、「PDF 出力」ボタンは出さない。画面がダークモードでも、印刷は白い背景のライトの配色で出す。印刷の既定の余白は上下左右 20mm とする。保存の既定のファイル名は「集計 」に続けて期間の見出しを付けたものにし、印刷が終わったらタブのタイトルはアプリ名に戻す。期間の入力に誤りがあるときはボタンを表示しない。

#### Scenario: PDF 出力のボタンを表示する
- **WHEN** ユーザーが「集計」ページで 2026年11月を集計している
- **THEN** 見出し「2026年11月」の横に、「PDF 出力」という名前のアイコンボタンが表示される

#### Scenario: 印刷ダイアログを開く
- **WHEN** 「PDF 出力」ボタンを選ぶ
- **THEN** ブラウザの印刷ダイアログが開き、送り先に「PDF に保存」を選ぶと集計を PDF として保存できる

#### Scenario: 期間の見出しから下だけを出す
- **WHEN** 2026年11月を集計しているときに、「PDF 出力」ボタンから PDF を保存する
- **THEN** PDF には「2026年11月」の見出し、合計時間・稼働日数と数え方の注記、週ごとの集計、プロジェクトごとの集計が出る
- **AND** サイドバー、ページの見出し「集計」、月の切り替え、期間の入力欄、「PDF 出力」ボタンは出ない

#### Scenario: 期間を指定した集計を出す
- **WHEN** 開始日に 2026-10-01、終了日に 2026-10-15 を指定して集計し、「PDF 出力」ボタンから PDF を保存する
- **THEN** PDF には「2026年10月1日〜2026年10月15日」の見出しとその期間の集計が出て、「月ごとの表示」と期間の入力欄は出ない

#### Scenario: 保存の既定のファイル名
- **WHEN** 2026年11月を集計しているときに「PDF 出力」ボタンを選ぶ
- **THEN** 印刷ダイアログで PDF に保存するときの既定のファイル名が「集計 2026年11月」になる
- **AND** 印刷ダイアログを閉じると、タブのタイトルはアプリ名に戻る

#### Scenario: ダークモードでもライトの配色で出す
- **WHEN** OS をダークモードにした状態で、「PDF 出力」ボタンから PDF を保存する
- **THEN** PDF は白い背景に黒い文字で出る

#### Scenario: 既定の余白を広く取る
- **WHEN** 印刷ダイアログの余白を「デフォルト」のまま、「PDF 出力」ボタンから PDF を保存する
- **THEN** PDF の集計は、用紙の上下左右の端から 20mm 内側に出る

#### Scenario: 入力に誤りがあるときはボタンを出さない
- **WHEN** 終了日を開始日より前にして「表示」を選ぶ
- **THEN** 集計と一緒に「PDF 出力」ボタンも表示されない
