# Design

## Context

- トップページの「今日の記録」（`TimeTracker`）と「過去の記録」（`EntryHistory` → `HistoryContent`）は、どちらも `components/time-entries/EntryList.tsx` で記録を表示している。`EntryList` は新しい順の記録を `groupByDate` で開始日（日本時間）ごとにまとめ、まとまりごとに `<h3>`（`formatDateHeading` の「2026年11月18日（水）」）と記録の `<ul>` を出す。まとまりの `<section>` は `aria-label` に日付を持つ
- 各記録の作業時間は `EntryItem` が `formatDuration(endedAt - startedAt)` で表示し、記録中なら「記録中」と出す
- 「集計」ページ（`lib/summary/summarize.ts`）は、記録ごとに作業時間を分に切り捨ててから足す（`durationMs`。記録中は 0）。記録の一覧に並ぶ作業時間を足した値と一致させるためである
- 日をまたぐ記録は終了時に日の境目で分けて保存されるので、終了済みの記録はどれも 1 日に収まる
- 記録の操作の後は Server Action が再検証し、サーバー部品の `TimeTracker`・`EntryHistory` が記録を読み直すので、`EntryList` で計算すれば合計も同じタイミングで新しくなる

## Goals / Non-Goals

**Goals:**
- 両ページの日付の見出しに、「集計」ページと同じ数え方の日の合計を出す

**Non-Goals:**
- 記録中の経過時間の表示（スコープ外。今も記録中の経過時間は出していない）

## Decisions

### 合計は `EntryList` の日付のまとまりごとに計算する

`groupByDate` の結果に合計（ミリ秒）を持たせ、見出しの行に表示する。両ページが `EntryList` を使っているので 1 か所の変更で済み、表示中の記録だけから計算するため DB の問い合わせも増えない。

代替案: サーバー側（リポジトリ）で日ごとの合計を SQL で求める → 一覧に出している記録と同じものを足すだけなので、別の問い合わせにする利点がない。

### 記録 1 件の作業時間の関数を `lib/time.ts` に置き、集計と共有する

`summarize.ts` の `durationMs` と同じ「分に切り捨て・記録中は 0」の計算を `lib/time.ts` に `entryDurationMs({ startedAt, endedAt })` として置き、`summarize.ts` もこれを使う。数え方を 1 か所にして、「集計」ページと一覧の合計がずれないようにする。`summarize.ts` の振る舞いは変わらないことを、既存の `summarize.test.ts` で確かめる。

### 表示は見出しの行の右端に合計だけを出し、読み上げには「合計」を添える

見出しの行を `flex justify-between` にし、左に今の `<h3>`（日付だけ）、右に合計を置く。見た目は記録の行の作業時間と同じく「3時間20分」だけにする（文字色は見出しと同じ `text-muted`、数字は `tabular-nums`）。日付の右に時間だけが並ぶと読み上げでは何の時間か分からないので、読み上げ専用の「合計」（`sr-only`）を前に付け、「合計 3時間20分」と読まれるようにする。文言は `lib/messages.ts` の `timeEntries.dayTotal` に置く。

`<h3>` の中には入れない。見出しの名前と `<section>` の `aria-label` を日付のままにして、今の見出しの読み上げとテストを変えないためである。

代替案:
- 見た目にも「合計 3時間20分」と出す → 行の作業時間の列と並べたとき冗長になる。見出しの右端の時間が日の合計であることは位置で分かるので、見た目は時間だけにする
- 記録中だけの日は合計を出さない → 「集計」ページは記録がない期間も「0分」と出しており、それに合わせて「0分」を出す

## Risks / Trade-offs

- [記録中の記録がある日は、合計が実際の作業時間より少なく見える] → 要望どおり記録中の時間は含めない。記録中の行には「記録中」と出ているので区別できる
- [日をまたいで記録中の記録は、開始日（前の日）のまとまりに出るが合計には入らない] → 終了すると日の境目で分けて保存され、それぞれの日の合計に入る
