# Proposal

## Why

使ってみて見た目に 3 つの気になる点がある。カレンダー（タイムライン・週のカレンダー）の帯は、長い記録ほどタスク名が帯の上下の真ん中に出て、開始時刻の位置と離れて読みにくい。「過去の記録」の「CSV 出力」は表示の切り替えのすぐ隣にあり、表示の切り替えと紛らわしい。ページの見出し（「過去の記録」など）は文字も上の余白も大きく、記録を表示できる縦の幅が減っている。

## What Changes

- タイムライン・週のカレンダーの帯の文字（タスク名と時刻）を、帯の上下の真ん中ではなく帯の上端に寄せて表示する
- 「過去の記録」の「CSV 出力」のボタンを、期間の見出しの行の右端に移す（一覧・週のカレンダーとも）。表示の切り替えは見出しの横のまま
- ページの見出し（「過去の記録」「集計」「プロジェクト」「アーカイブしたプロジェクト」、プロジェクトの詳細・作成）の文字を小さくし（30px → 20px）、ページの上下の余白（48px → 24px）と見出しの下の余白（32px → 16px）を小さくする。トップページ（見出しは読み上げ用だけ）も上下の余白をそろえる

### スコープ外（やらないこと）

- サイドバー・画面上部のロゴやナビゲーションの大きさ
- 一覧の見出し（「今日の記録」「2026年11月」など）の大きさ
- 「集計」の PDF 出力（印刷）の見た目（印刷では見出しを出さず、余白も今までどおり）

### README.md の更新

README の「使い方」の「CSV 出力」の説明にある「見出しの横」を「見出しの行の右端」に直す。ほかは見た目の調整で、README の記載に影響しない。
