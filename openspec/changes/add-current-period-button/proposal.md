# Proposal

## Why

「過去の記録」や「集計」で前の月・前の週をさかのぼったあと、今月（今週）に戻るには「次の月」「次の週」を何度も押すか、サイドバーから開き直すしかない。前後のボタンの右に「今月」「今週」のボタンを置き、1 回で今の期間に戻れるようにする。

## What Changes

- 「過去の記録」の一覧と「集計」の月の切り替えを「‹ › 今月」の並びにし、「前の月」「次の月」の右に「今月」の文字のボタンを置く。選ぶと今月を表示する
- 「過去の記録」の週のカレンダーの週の切り替えを「‹ › 今週」の並びにし、「前の週」「次の週」の右に「今週」の文字のボタンを置く。選ぶと今週を表示する
- 今月（今週）を表示しているときは、「次の月」「次の週」と同じく押せない状態で表示する（ボタンの位置は変えない）
- 「今月」は今月を URL に明示する（`?month=2026-11`）。「過去の記録」で表示にカレンダーを選んでいても、一覧の今月を出すため

### スコープ外（やらないこと）

- 期間を指定しているときの表示（今までどおり「月ごとの表示」で今月に戻る）
- トップページ（今日の記録）
- 「今日」を選ぶボタンや、日付の入力欄の中の「今日」ボタン

### README.md の更新

README の「使い方」の「過去の記録」と「集計」の月・週の切り替えの説明に、「今月」「今週」のボタンを追記する。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `time-tracking`: 「過去の記録」の月の切り替えと週の切り替えに、今月・今週を表示するボタンの要件を加える
- `time-summary`: 「集計」の月の切り替えに、今月を表示するボタンの要件を加える

## Impact

- `lib/time-entries/history.ts`: 月の表示に今月の値（`thisMonth`）、週の表示に今週の値（`thisWeek`）を足す
- `components/time-entries/PeriodControls.tsx`・`WeekControls.tsx`: 「今月」「今週」の文字のボタン（`TextLink`、今なら押せない `TextButton`）を足す
- `lib/messages.ts`: 「今月」「今週」の文言
- `README.md`
- 依存パッケージ・DB の変更なし
