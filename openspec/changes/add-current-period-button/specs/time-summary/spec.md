## ADDED Requirements

### Requirement: 集計の今月を表示するボタン
システムは、「集計」ページの月の切り替えで、「前の月」「次の月」の右に「今月」の文字のボタンを表示し、選ぶと今月の集計を表示しなければならない（SHALL）。今月を集計しているときは、ボタンを押せない状態で表示する。期間を指定しているときは表示しない（「月ごとの表示」で今月に戻る）。

#### Scenario: 集計で今月に戻る
- **WHEN** 2026年11月24日に、「集計」で 2026年9月 を集計しているときに「今月」を選ぶ
- **THEN** 見出しが「2026年11月」になり、11 月の集計が表示される

#### Scenario: 今月を集計しているとき
- **WHEN** 「集計」で今月を集計している
- **THEN** 「今月」は押せない
