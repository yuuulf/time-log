# Design

## Context

- 記録中の枠（`components/time-entries/StartStopForm.tsx`）は、見出し「記録中のタスク」の下の 1 行に、タスク名と、その右にプロジェクト（`ProjectIcon` を `decorative` にして名前を文字で並べたもの）を `flex-wrap` で並べている
- サイドバー（`components/layout/RunningTaskView.tsx`）は、タスク名の後ろに `ProjectIcon`（`role="img"`、名前で読み上げ）を置いている
- 記録の一覧（`EntryItem`）は、プロジェクトのボタン → タスク名の順

## Goals / Non-Goals

**Goals:**
- 記録中の枠とサイドバーでも、見た目と読み上げの順を「プロジェクト → タスク名」にそろえる

**Non-Goals:**
- サイドバーでのプロジェクト名の文字表示、一覧の変更

## Decisions

### 1. 記録中の枠

- 見出しの下に、プロジェクトがあるときだけプロジェクトの行（`<p>`、アイコン（`decorative`）とプロジェクト名、`text-sm` の控えめな色）を置き、その下にタスク名の行（今と同じ太さ）を置く。DOM の順も同じにして、読み上げがプロジェクト名 → タスク名になるようにする
- プロジェクトがないときはプロジェクトの行を出さない（「プロジェクトなし」は出さない。記録中の枠の高さが変わるが、表示する情報がないので空けない）

### 2. サイドバー

- タスク名の行の先頭に `ProjectIcon`（`role="img"`、`title`）を置き、タスク名との間を少し空ける（`mr-2`）。アイコンは名前を文字で出さないので、読み上げの対象のままにする（プロジェクト名 → タスク名の順に読まれる）

## Risks / Trade-offs

- [記録中の枠の高さが、プロジェクトの有無で 1 行分変わる] → 記録を切り替えたときに下の一覧が少し動くが、表示する内容に合わせた高さを優先する
