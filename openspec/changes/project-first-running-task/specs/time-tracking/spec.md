# Spec Delta

## MODIFIED Requirements

### Requirement: 記録の開始
システムは、ユーザーがタスク名を入力して「開始」ボタンを選んだとき、現在時刻を開始時刻とする記録中の記録を作らなければならない（SHALL）。タスク名は省略でき、前後の空白は取り除く。200 文字を超えるタスク名は受け付けない。タスク名と一緒にプロジェクトを 1 つ選べる（選ばなくてもよい）。プロジェクトは、記録の一覧と同じ色のアイコン付きのプルダウン（「記録のプロジェクトの表示」に従う）で選び、選択肢は「プロジェクトなし」と登録したプロジェクトで、最初は「プロジェクトなし」を選んだ状態にする。記録を始めたら、タスク名の入力欄とプロジェクトの選択は最初の状態に戻す。

#### Scenario: タスク名を入力して開始する
- **WHEN** 記録中のタスクがない状態で、タスク名に「資料作成」と入力して「開始」ボタンを選ぶ
- **THEN** 「資料作成」が記録中として表示され、開始時刻に現在時刻が表示される

#### Scenario: タスク名を入力せずに開始する
- **WHEN** タスク名を空のまま「開始」ボタンを選ぶ
- **THEN** 記録が始まり、タスク名の代わりに「（タスク名なし）」と表示される

#### Scenario: タスク名が長すぎる
- **WHEN** 201 文字のタスク名を入力して「開始」ボタンを選ぶ
- **THEN** 記録は始まらず、タスク名は 200 文字以内で入力するよう案内が表示される

#### Scenario: プロジェクトを選んで開始する
- **WHEN** タスク名に「資料作成」と入力し、プロジェクトのプルダウンで「社内ツール」を選んで「開始」ボタンを選ぶ
- **THEN** 「資料作成」が「社内ツール」のプロジェクトで記録中になり、記録中の枠の「資料作成」の上の行に「社内ツール」の色のフォルダのアイコンと名前が表示される
- **AND** プロジェクトのプルダウンは「プロジェクトなし」に戻る

#### Scenario: プロジェクトを選ばずに開始する
- **WHEN** プロジェクトを「プロジェクトなし」のまま「開始」ボタンを選ぶ
- **THEN** プロジェクトの紐づかない記録が始まり、プロジェクトのアイコンは表示されない

#### Scenario: 選んだプロジェクトが削除されていた
- **WHEN** 開始ボタンを選ぶ前に、選んでいたプロジェクトが別の画面で削除されていた
- **THEN** 記録は始まらず、プロジェクトが見つからない旨が表示される

#### Scenario: 開始のプロジェクトの選択肢に色を表示する
- **WHEN** 「社内ツール」「A 社サイト改修」を登録した状態で、記録の開始のプロジェクトのプルダウンを開く
- **THEN** 「プロジェクトなし」「社内ツール」「A 社サイト改修」が並び、「社内ツール」と「A 社サイト改修」にはそれぞれの色のアイコンが付く

### Requirement: 記録のプロジェクトの表示
システムは、プロジェクトの紐づいた記録を表示するとき、プロジェクトの色で塗りつぶしたフォルダのアイコンを、タスク名より前に表示しなければならない（SHALL）。記録の一覧（トップページ・「過去の記録」）では、タスク名の左側にアイコンとプロジェクト名を文字で並べ、プロジェクトの紐づかない記録には「プロジェクトなし」と表示する。一覧のプロジェクトの表示はプロジェクトを選ぶプルダウンを開くボタンを兼ね、選択肢にも色のアイコンと名前を表示する。記録の開始のプロジェクトの選択にも同じプルダウンを使う。トップページの記録中の枠では、タスク名の上の行にアイコンとプロジェクト名を表示する。サイドバーの記録中のタスクでは、タスク名の左側にアイコンだけを表示する。アイコンにポインタを合わせるとプロジェクト名を表示し、スクリーンリーダーではタスク名より先にプロジェクト名を読み上げる。記録中の枠とサイドバーでは、プロジェクトの紐づかない記録にアイコンを表示しない。

#### Scenario: プロジェクトの紐づいた記録を一覧で見る
- **WHEN** 「社内ツール」のプロジェクトの「資料作成」の記録がある状態でトップページを開く
- **THEN** 一覧の「資料作成」の左側に「社内ツール」の色のフォルダのアイコンと「社内ツール」の文字が表示される

#### Scenario: プロジェクトのアイコンを読み上げる
- **WHEN** スクリーンリーダーで一覧の「資料作成」の記録のプロジェクトのボタンにフォーカスする
- **THEN** プロジェクトを選ぶボタンであることと、今のプロジェクト名「社内ツール」が読み上げられる

#### Scenario: トップページの記録中の枠ではプロジェクト名も表示する
- **WHEN** 「社内ツール」のプロジェクトで「資料作成」を記録中にトップページを開く
- **THEN** 記録中の枠の「資料作成」の上の行に、「社内ツール」の色のフォルダのアイコンと「社内ツール」の文字が表示される
- **AND** 読み上げでは「社内ツール」に続いて「資料作成」が読まれる
- **AND** サイドバーでは、プロジェクト名は文字で表示されず、アイコンだけが表示される

#### Scenario: 記録中のタスクのプロジェクト
- **WHEN** 「社内ツール」のプロジェクトで「資料作成」を記録中に、いずれかのページを開く
- **THEN** サイドバーの記録中のタスクの「資料作成」の左側に「社内ツール」の色のフォルダのアイコンが表示される
- **AND** アイコンにポインタを合わせると「社内ツール」と表示され、読み上げでは「社内ツール」に続いて「資料作成」が読まれる

#### Scenario: プロジェクトの紐づかない記録
- **WHEN** プロジェクトの紐づかない記録を一覧に表示する
- **THEN** その記録にはプロジェクトのアイコンが表示されず、プロジェクトの欄に「プロジェクトなし」と表示される

#### Scenario: プロジェクトの紐づかない記録を記録中にする
- **WHEN** プロジェクトの紐づかない「資料作成」を記録中にトップページを開く
- **THEN** 記録中の枠とサイドバーにはプロジェクトのアイコンと行が表示されず、「資料作成」だけが表示される

#### Scenario: プルダウンの選択肢に色を表示する
- **WHEN** 「社内ツール」「A 社サイト改修」を登録した状態で、一覧の記録のプロジェクトのプルダウンを開く
- **THEN** 「プロジェクトなし」「社内ツール」「A 社サイト改修」が並び、「社内ツール」と「A 社サイト改修」にはそれぞれの色のアイコンが付き、今のプロジェクトが選ばれている表示になる
- **AND** 上下の矢印キーで選択肢を移り、Enter キーで選べ、Escape キーで選ばずに閉じられる
