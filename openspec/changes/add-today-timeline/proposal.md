# Proposal

## Why

「今日の記録」は新しい順の一覧なので、1 日のどこに空きがあるのか、記録どうしが重なっていないかが一目では分からない。また、記録を付け忘れた時間を後から足す方法がない（今は「開始」した記録しか作れない）。「今日の記録」を時間軸のタイムラインでも表示できるようにし、空いている時間を選ぶだけで記録を追加できるようにする。

## What Changes

- 「今日の記録」の見出しの横に、表示を一覧とタイムラインで切り替えるアイコンボタン（名前は「一覧」「カレンダー」）を置く。最後に選んだ表示を覚えておき、ページを開き直してもその表示で開く（最初は一覧）
- タイムラインは、カレンダーの 1 日表示のように上から 0 時〜24 時の時刻の目盛りを並べ、今日に開始した記録をプロジェクトの色の帯（タスク名と時刻入り）で置く。記録中の記録は、終了するまでは開始時刻から決まった高さ（30 分ぶん）の帯で置く。今の時刻に線を引き、開いたときは今の時刻のあたりまでスクロールする。時間が重なる記録は横に並べる。日付の見出しと合計時間は一覧と同じく表示する
- タイムラインの空いている場所を選ぶと、その場に小さな入力欄（タスク名・プロジェクト・開始時刻・終了時刻）が開く。開始時刻には選んだ時刻を 15 分単位に切り捨てた時刻が、終了時刻にはその 30 分後（次の記録の開始・今の時刻のほうが早ければそこまで）が入っている。「追加」で終了済みの記録として保存する。今より後の場所を選んでも入力欄は開かない
- タイムラインの記録の帯を選ぶと、同じ入力欄が今の値の入った状態で開き、タスク名・プロジェクト・時刻の修正（「保存」）と削除（確認してから）ができる。記録中の記録は、一覧と同じく終了時刻を直せない
- 入力の誤り（200 文字を超えるタスク名、終了が開始より前、未来の時刻など）は既存の修正と同じ規則で確かめ、入力欄に理由を表示する。日をまたぐ時刻は既存の「日をまたぐ記録の分割」に従って分ける
- 既存の「記録の修正」の要件にある「修正のためのフォームを別に開く操作は設けない」は、一覧の表示のことと明記する

### スコープ外（やらないこと）

- 「過去の記録」ページのタイムライン表示
- 帯のドラッグによる移動・長さの変更、ドラッグでの範囲を選んだ追加
- 一覧の表示からの記録の追加、キーボードだけでの記録の追加（タイムラインの空いている場所はポインタで選ぶ）
- タイムラインからの記録の再開（一覧の表示で行う）
- 記録の重なりを禁止・警告すること

### README.md の更新

README の「使い方」の「今日の記録」の説明に、タイムラインへの切り替えと、タイムラインからの追加・修正・削除を追記する。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `time-tracking`: 「今日の記録」の表示の切り替え、タイムラインの表示、タイムラインからの記録の追加、タイムラインでの記録の修正と削除の要件を加える。「記録の修正」の要件で、フォームを開かずに修正するのは一覧の表示のことと明記する

## Impact

- `components/time-entries/TimeTracker.tsx`: 表示の設定（Cookie）を読み、一覧かタイムラインを出す
- `components/time-entries/`（新規）: 表示の切り替えボタン、タイムライン、記録の入力欄のコンポーネント
- `lib/time-entries/timeline.ts`（新規）: 帯の位置・重なりの段の計算、選んだ場所からの初期の時刻の計算
- `lib/time-entries/actions.ts`・`repository.ts`・`validation.ts`: 終了済みの記録を追加する Server Action と保存処理（日をまたぐときは分ける）
- `lib/messages.ts`: ボタンの名前・入力欄の文言を追加
- `README.md`: 「使い方」に追記
- 依存パッケージ・DB のスキーマの変更なし
