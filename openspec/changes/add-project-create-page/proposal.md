# Proposal

## Why

「プロジェクト」ページの上部に登録欄が常にあり、一覧が下に押し出されて見にくい。登録は「追加」ボタンから開く専用の登録画面で行い、一覧ページは一覧に集中させる。登録画面は詳細画面と同じ並びにして、項目の見た目をそろえる。

## What Changes

- 「プロジェクト」ページから登録欄をなくし、一覧の見出しの横に「＋ 追加」ボタン（プラスのアイコンと文字の「追加」）を置く。選ぶと登録画面（`/projects/new`）に移動する
- 登録画面は詳細画面と同じ並び（一覧へ戻るリンク、見出し、名前・色・クライアント名・説明の欄）にする。見出しは「プロジェクトの登録」
- 登録画面の「プロジェクトを作成」ボタンで作成する。作成できたら一覧に戻り、作ったプロジェクトが一覧の最後に表示される。入力に誤りがあるときは作成せず、入力した値を残して理由を表示する
- 一覧にプロジェクトがないときの文言を、「追加」ボタンから登録するよう案内する文言に変える
- 登録画面を開いているときも、サイドバーの「プロジェクト」を選ばれている表示にする

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `projects`: 「プロジェクトの一覧」に「追加」ボタンを加え、「プロジェクトの登録」を登録画面での作成に変える
- `app-shell`: 「画面幅への対応」の対象と「サイドバー」の選ばれている表示に、プロジェクトの登録画面を加える

## スコープ外

- 詳細画面の編集のしかた（その場の編集のまま）
- 登録画面からの作成後に詳細画面へ移ること（一覧に戻る。ユーザーの判断）
- 入力の途中で一覧へ戻るときの確認（入力した値は捨てる）
- 登録の入力チェックの変更（今と同じ）

## README.md の更新

必要。使い方の「プロジェクト」の登録の説明を、一覧の「追加」ボタンから登録画面を開き「プロジェクトを作成」で作る形に書き換える。

## Impact

- 新規: `app/projects/new/page.tsx`、`components/projects/ProjectFields.tsx`（詳細画面と登録画面で共通の項目の並び）、`components/ui/TextButton.tsx`（アイコンと文字のボタン・リンク）
- 変更: `components/projects/ProjectForm.tsx`（登録画面のフォームに）、`ProjectDetail.tsx`（共通の並びを使う）、`ProjectsContent.tsx`（登録欄をなくし「追加」ボタン）、`lib/messages.ts`、README.md
- サーバー側（`createProjectAction`・入力チェック）とデータは変えない
- 新しい依存パッケージ: なし
