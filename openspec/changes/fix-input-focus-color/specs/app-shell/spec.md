# Spec Delta

## ADDED Requirements

### Requirement: 入力欄のフォーカスの表示
システムは、入力欄（テキスト・日付・日時・複数行の入力欄と、入力欄と同じ見た目のプルダウン）にフォーカスしたとき、その欄の枠をアプリのテーマ色（primary）で表示しなければならない（SHALL）。ブラウザ既定のフォーカスの表示（青い枠など）は出さない。入力エラーのある欄は、フォーカス中も枠をエラーの色で表示する。ライトモードとダークモードのどちらでも、そのモードのテーマ色を使う。

#### Scenario: 記録の開始フォームのタスク名にフォーカスする
- **WHEN** ユーザーがトップページでタスク名の入力欄をクリックする
- **THEN** 入力欄の枠がテーマ色で表示され、ブラウザ既定の青い枠は表示されない

#### Scenario: 期間の指定の日付にフォーカスする
- **WHEN** ユーザーが過去の記録の画面で開始日の入力欄にフォーカスする
- **THEN** 入力欄の枠がテーマ色で表示される

#### Scenario: プロジェクトのフォームの入力欄にフォーカスする
- **WHEN** ユーザーがプロジェクトの登録画面で名前・クライアント名・説明のいずれかの入力欄にフォーカスする
- **THEN** その入力欄の枠がテーマ色で表示される

#### Scenario: プロジェクトのプルダウンにキーボードでフォーカスする
- **WHEN** ユーザーがトップページで Tab キーを押してプロジェクトのプルダウンにフォーカスする
- **THEN** プルダウンの枠がテーマ色で表示される

#### Scenario: 記録一覧の入力欄にフォーカスする
- **WHEN** ユーザーが記録一覧でタスク名の入力欄にフォーカスする
- **THEN** 入力欄の枠がテーマ色で表示される

#### Scenario: 入力エラーのある欄にフォーカスする
- **WHEN** プロジェクトの登録画面で名前を空にして登録し、エラーになった名前の入力欄にフォーカスする
- **THEN** 入力欄の枠はエラーの色のまま表示される

#### Scenario: フォーカスを外す
- **WHEN** ユーザーがフォーカスしていた入力欄から別の場所へフォーカスを移す
- **THEN** 入力欄の枠はフォーカス前の色に戻る
