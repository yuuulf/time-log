# Proposal

## Why

いまのファビコンは `create-next-app` が置いた Next.js の初期のもので、ブラウザのタブで TimeLog だと見分けられない。サイドバーのアプリ名も文字だけなので、用意したロゴ（時計とチェックの絵）をファビコンとサイドバーに使い、アプリの見た目をそろえる。

## What Changes

- ファビコンを TimeLog のロゴに変える。ライトモードでは `icon_light.png`、ダークモードでは `icon_dark.png` の絵を出す
- ロゴの絵の外側の地（ライト用は白、ダーク用は濃い灰色）を透明にし、ファビコンでもサイドバーでも周りの背景が透けて見えるようにする
- `create-next-app` の初期のファビコン（`app/favicon.ico`）を削除する
- サイドバーのアプリ名「TimeLog」の左にロゴを表示する。ロゴも画面のライト・ダークに合わせて出し分ける
- 幅 768px 未満で画面上部に出すアプリ名にも、同じようにロゴを付ける（アプリ名を表示する場所の見た目をそろえるため）
- ロゴは飾りとして扱い、アプリ名のリンクの名前は今までどおり「TimeLog」のままにする

### スコープ外（やらないこと）

- ホーム画面に追加したときのアイコン（`apple-icon`）や Web アプリのマニフェスト
- SNS で共有したときの画像（Open Graph 画像）
- ロゴの絵そのものの作り直し・色の調整（透過のほかは元の絵のまま使う）
- 画面の配色（テーマ）の変更や、ライト・ダークを手で切り替える機能

### README.md の更新

README には画面の見た目やファビコンについての記述がないため、更新は不要と見込む。実装の最後に改めて確認する。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `app-shell`: 「ファビコン」と「アプリ名のロゴ」の要件を加える（既存の要件は変えない）

## Impact

- `public/`（新規）: ロゴの画像（ライト用・ダーク用）
- `app/favicon.ico`: 削除
- `app/layout.tsx`: メタデータにファビコン（ライト・ダーク）を指定
- `components/layout/Sidebar.tsx`・`components/layout/SidebarShell.tsx`: アプリ名の横にロゴ
- 共通部品としてロゴの部品を `components/layout/` に追加
- 依存パッケージの追加はなし
